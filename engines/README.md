# Engines và model assets

Thư mục này dành cho model weights, file license và tài nguyên được bundle cùng Python backend. Mỗi asset phải ghi rõ upstream, phiên bản, checksum và điều khoản phân phối.

Không đặt source code xử lý nghiệp vụ tại đây; pipeline nằm trong [Python backend](../backend/README.md). Không commit model lớn trước khi quyết định kích thước cài đặt và license.
