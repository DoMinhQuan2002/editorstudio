# [cpu] is deliberate for portability, but this machine reports a CUDA GPU and
# BiRefNet (see video_editor/cutout.py) is slow enough on CPU that the desktop
# poll can outlast a run. To move cutouts onto the GPU, in the backend venv:
#   pip uninstall -y onnxruntime
#   pip install onnxruntime-gpu
# onnxruntime-gpu needs matching CUDA/cuDNN runtime libraries on PATH; if it
# cannot find them it falls back to CPU or fails to create a session, so verify
# with:  python -c "import onnxruntime; print(onnxruntime.get_available_providers())"
# and expect CUDAExecutionProvider in the list.
